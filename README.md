# 楽園をつくろう 🌳

ハルマゲドンの後、静かになった大地を一日ずつ楽園にしていく、家族のための穏やかなゲームです。
家族の崇拝などで使い、**楽園への希望を鮮明に、リアルに保つ**ことを目的にしています。

内容は jw.org の説明（地球は滅びない／日ごとに楽園へ前進する／家と食物と満足のいく仕事／病気がない／動物との平和／復活した人たちを迎える）を土台にしています。聖句は箇所と短い要約を載せ、本文は jw.org で読めるようにリンクしています。

## 遊び方
1. **はじめる**を押す（音が出ます）。
2. 下の道具を選び、大地のマスを押します。
   - 🪨整地 → 💧水路で泉から水を引く → ⛲井戸
   - 🌾畑・🍇果樹・🌸花（水の近くで育ちます）
   - 🏠家（水と実った食物が必要）→ 🤝迎える（復活した人を迎え、名前を付けます）
   - 🐑動物（緑が増えるとやって来ます）・🪧看板（家族の希望を立てます）
3. 労力を使い切ったら **🌙一日を終える**。夜の間に作物が育ち、朝には労力が戻ります。迎えた人が増えると、働き手も増えます。
4. 節目で **📖黙想カード** が見つかります。家族で読んで、問いについて話し合ってください。
5. **📝希望ノート** に家族一人一人の「楽園でしたいこと」「迎えたい人」を書いておくと、看板や迎える場面で使えます。

保存はこの端末のブラウザに自動で残ります。機種を変えるときは ⚙設定 から書き出し／読み込みができます。

## 家族の崇拝での使い方の例
- 毎週10〜15分、交代で操作して一日分を進める。
- 出てきた黙想カードを一枚読み、問いについて一人ずつ話す。
- 希望ノートに書いたことを、看板として楽園に立てる。

## 章（すべて遊べます）
| 章 | ひらく条件 | できること |
|---|---|---|
| 第1章 清められた大地 | 最初から | 整地・水路・井戸・畑・果樹・花・家・動物・迎える・看板 |
| 第2章 再会 | 1人迎え、谷の楽園度35 | 🏫学びの家・📖教える。希望ノートの「迎えたい人」を迎えると再会の場面 |
| 第3章 動物との平和 | 5人迎え、3人に教える | おおかみ・ひょう・ライオン・熊も迎えられる |
| 第4章 地球全体へ | 動物8匹（野生2匹） | 🗺海辺・山里・荒れ野へ広げる（一日を終えるとすべての地域で育つ） |
| 第5章 歩いて見る | 谷以外の2地域で楽園度25 | 🚶自分たちの楽園の中を一人称で散歩。家や看板に近づくと読み上げ |

いつでも使える機能：🗓今週のテーマ（週替わりのカードと家族の活動）、📷記念写真、🔈カードの読み上げ、季節（春の花びら・秋の色づき）。
黙想カードは全20枚です。

## 技術
ビルド不要の静的サイト（HTML / ES Modules / Canvas 2D / Web Audio）。画像・音声ファイルは使わず、すべてその場で描画・合成しています。

```
npm test      # ゲームロジックのテスト
python3 -m http.server   # http://localhost:8000 で確認
```
`?clock=0.86` を付けると夜の景色、`?walk=1` で歩いて見る（第5章のとき）を確認できます。
