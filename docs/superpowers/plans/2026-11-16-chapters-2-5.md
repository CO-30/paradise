# 第2〜5章 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 章の進行・地域・教える・野生動物・再会の場面・歩いて見る・随時機能を加え、全章を遊べるようにする。
**Architecture:** 既存の `game.js`（純粋ロジック）を拡張し、`walk.js`（一人称ビュー）を新設。UIは `main.js`。
**Tech Stack:** 変更なし（ES Modules / Canvas 2D / Web Audio / speechSynthesis）。
**Spec:** `docs/superpowers/specs/2026-11-16-chapters-2-5-design.md`

## Global Constraints
- 外部素材・CDNなし。聖句は箇所＋自分の言葉の要約＋jw.org リンク。
- 第1章の保存データはそのまま読み込める。

## Review Focus
1. 第1章の古い保存データ → 谷として読み込み、chapter=1（テスト）。
2. 地域を移動しても他地域のマスが失われない、保存→読み込みでも同じ（テスト）。
3. 章の条件を満たす前に新しい行動は拒否（テスト）。
4. 歩行で家・海・地図外に入れない（`canWalk` テスト）。
5. speechSynthesis がない端末 → 読み上げボタンを出さない。
